# Task 3: SQL for Data Analysis

This project demonstrates SQL-based data analysis using a small ecommerce dataset in SQLite. The database includes customer, product, order, and order-item data, and it covers the required SQL operations: `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `JOIN`, `subqueries`, `aggregate functions`, `views`, and `indexes`.

## Project Files

- `ecommerce_analysis.sql` — schema, sample data, views, indexes, and analysis queries
- `build_database.py` — creates the SQLite database from the SQL script
- `generate_screenshots.py` — renders query results into PNG screenshots
- `ecommerce.db` — SQLite database generated by the script
- `screenshots/` — output examples of SQL query results

## Database Design

Tables included:

- `customers`
- `products`
- `orders`
- `order_items`

## Example SQL Skills Included

- `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
- `INNER JOIN`, `LEFT JOIN` (and SQLite equivalent for `RIGHT JOIN`)
- Subqueries for filtered analysis
- `SUM`, `AVG`, `COUNT`, `ROUND`
- `CREATE VIEW`
- `CREATE INDEX`
- `EXPLAIN QUERY PLAN`

## How to Run

1. Open a terminal in the project folder.
2. Run:

```bash
python build_database.py
python generate_screenshots.py
```

3. The SQLite database will be created as `ecommerce.db` and screenshots will be saved in `screenshots/`.

## Notes

The dataset is intentionally small and readable so the SQL logic is easy to follow while still covering realistic ecommerce analysis tasks.
